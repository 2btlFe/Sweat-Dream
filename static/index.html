Dream-1 Simulator

Type a task, press Run, and watch Dream-1 move two robot arms in the simulator.

No Dream API key found. Put DREAM_API_KEY=... in ~/.dreamlabs/credentials and restart (see README).
A Dream-1 run is data collection: Dream-1 works, and when it fails the recovery script takes over; no human. If the script cannot recover, the run ends there and is saved as a failure: recover it by hand afterwards in Recordings (below).

Mouse: click an object in any camera to move a hand above it (a wrist camera moves its own arm) · drag in the top camera to move the hand along the table · wheel for up / down.
